# dspy-security-bench: a reproducible harness for measuring prompt-injection robustness in tool-using LLM agents

> Zenodo 软件记录（v0.12.0，2026-08-19 发布）。raw 快照：`raw/articles/doi-org-10-5281-zenodo-22003465.md`（仅 Zenodo 着陆页）。

## 摘要

dspy-security-bench 是一个 Python harness，用于测量 tool-using LLM agent 抵抗间接 prompt injection 的能力。它包装 AgentDojo 的任务环境，在此基础上加了一层可复现的测量协议：协议冻结并哈希化、同时报告任务效用（utility）与攻击抵抗率、对任务对（task pairs）做 cluster-bootstrap 置信区间，并设有一条 confirmed/provisional 判据来决定一个结果何时稳定到可以当作结论陈述。

## 要点

按 Zenodo 记录的描述，该工具由几组机制构成：

- **测量协议层**：冻结且哈希化的 measurement protocol——评测配置一经确定即不可悄悄改动，结果可与确切的协议版本绑定。这对 [[agent-evaluation]] 的「环境漂移导致分数不可比」问题是一个直接的工程回应。
- **双指标报告**：任务效用与攻击抵抗并列报告，而不是只报安全性——避免「把 agent 捆死就安全了」的 trivial 解。
- **统计层**：对任务对做 cluster-bootstrap 置信区间；confirmed/provisional 判据区分「稳定结论」与「初步观察」。
- **框架桥接**：自述提供连接 OpenAI Agents SDK、LangChain、Pydantic AI、CrewAI、AutoGen、MCP 及自定义循环的桥接，统一到一个框架中立的契约上。
- **证据与审计组件（ImpactTwin / ProofRun / ControlTwin / RepeatControlTwin / IncidentTwin / FederalProof 等）**：记录描述了成对照的政策开/关实验、重复执行的不确定性界、GitHub/Sigstore 出处绑定、内容寻址的社区提交、离线可重算的证据注册表，乃至导出 OSCAL 1.2.2 评估结果。这部分组件多、承诺大，尤其需要核对实际代码后再采信。
- 发布物为一个 7.2 MB 的 zip（含 md5 校验值），代码仓库在 github.com/immu4989/dspy-security-bench（v0.12.0 标签）。
